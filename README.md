# LangChain

A hands-on learning repository documenting my journey with **LangChain** through practical Python examples and implementations.

This repository covers the core components of LangChain, from working with LLMs and prompts to building chains, exploring retrieval techniques, and implementing Retrieval-Augmented Generation (RAG).

## 📚 Topics Covered

- **Models** – Working with language models and chat models.
- **Prompts** – Creating and managing prompt templates.
- **Chains** – Combining components into reusable workflows.
- **Document Loaders** – Loading data from different sources.
- **Text Splitters** – Splitting documents into manageable chunks.
- **Vector Stores** – Storing and searching document embeddings.
- **Retrievers** – Retrieving relevant information for queries.
- **RAG** – Building retrieval-augmented generation workflows.
- **Output Parsers** – Structuring and parsing LLM responses.
- **Structured Outputs** – Working with structured model responses.
- **Tools** – Connecting LLMs with external functions and capabilities.
- **Runnables** – Composing and executing LangChain components.
- **Pydantic** – Defining structured data schemas and validation.
